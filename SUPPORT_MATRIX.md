# Dih destek matrisi

- Launcher: GitHub `sürümler/<tam-minecraft-surumu>/` altındaki her profili Fabric olarak kurar.
- Dih Client yerleşik adapter: Minecraft **1.21.11**, Java 21, Fabric Loader 0.19.3, Fabric API 0.141.6+1.21.11.
- Başka Minecraft sürümü: launcher çalışır; Dih Client kullanılacaksa o sürüm için ayrı derlenmiş `dih-client.jar` dosyası profil `mods/` klasörüne konur.
- Replay: yerleşik değildir; sürüme uygun ReplayMod JAR'ı profil `mods/` klasöründen dağıtılır.
